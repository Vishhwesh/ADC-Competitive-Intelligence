Fig. 05 — Methodology

How this dataset was built

Source: ClinicalTrials.gov API v2, queried on intervention + condition fields for antibody-drug conjugate oncology trials (773 raw results).
  • Classification: a study was confirmed as ADC-related if its intervention name matched a known payload/linker suffix (e.g. vedotin, deruxtecan, govitecan), its title/intervention description explicitly stated "antibody-drug conjugate," or its code name matched a manually verified list of investigational ADCs lacking suffix nomenclature.
  • Result: 540 of 773 raw matches (70%) confirmed as true ADC oncology trials; 233 excluded as false positives (vaccines, CAR-T, imaging studies, unrelated combination agents).
  • Target antigen extraction: pattern-matched against 23 known oncology ADC targets across trial title, condition, and intervention description text. 46% of trials had no extractable target — mostly very early-phase, code-named compounds with minimal public disclosure. This is a genuine data limitation, not an error.
